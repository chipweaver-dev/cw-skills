# 评审与交付检查表

每项用 `[ ]` 勾选；不能勾的写原因与下一步。Gate 只接受 `Approved` / `Revise`，不接受“差不多”。

## 1. 开工前（P0）

- [ ] 受众与先修知识已写明
- [ ] 平台、画幅、分辨率、帧率已写明
- [ ] 总时长 + 允许区间已定
- [ ] 逐段落时间预算表存在，且各段之和等于总时长
- [ ] 风格 playbook 已选（技术类默认 `minimalist-diagram`）
- [ ] 每个叙事单元的固定字段模板已定
- [ ] 素材清单与来源分级已定
- [ ] TTS 音色/语速/采样率/格式/情绪已定
- [ ] 是否需要音乐已确认（不要默认省略）
- [ ] 凭证来源已确认（环境变量/项目 `.env`），且不会进入产物
- [ ] `pre-production/`、`production/<version>/toolbox/`、`post-production/`、`.tmp/` 已建立
- [ ] 原始素材已就位并只读；brief 引用路径逐一核对存在

## 2. Gate 1：Pre-Production Review

### 2.1 Brief 与结构

- [ ] 一句话承诺清晰：观众看完能回答哪个问题
- [ ] 前 3 秒有钩子（反常识/数字/冲突）
- [ ] 范围边界写明（不讲什么）
- [ ] 每个单元有“旧瓶颈 → 新机制 → 新代价”
- [ ] 相邻单元用“上一个留下的新瓶颈”衔接
- [ ] 没有名词年表式堆砌
- [ ] 段落顺序与预算匹配；每段至少 20 s

### 2.2 事实

- [ ] `research/sources.md` 存在，来源分级正确
- [ ] `research/facts.json` 每个单元一行，每格有 `source_id`
- [ ] 查不到的值写 `N/A`，没有推测值
- [ ] 所有上屏数字来自事实表，script 没有二次转述
- [ ] `[实测]` / `[模型]` 标注规则已写明
- [ ] 片尾参考资料格式已定（编号/标题/出版者/年份/URL 或页码）

### 2.3 脚本

- [ ] 旁白只讲因果/论点，数字由画面承载
- [ ] 单屏最多 1 句论点 + 1 组规格/数据
- [ ] 字数按实测语速反写（默认 4.2 字/秒预算）
- [ ] 术语首次“中文（English）”，之后用英文
- [ ] 读音层替换表已列，`expect_occurrences` 已核对
- [ ] 章节卡/片尾卡标为 display-only，不计旁白字数
- [ ] 每拍有 `vo / 屏幕信息 / 预算 / 关键词 / 舞台绑定`

### 2.4 分镜与视觉

- [ ] 每拍画面主体、构图、进入顺序、运动、转场、停留时间可执行
- [ ] 信息密集卡有分级揭示（0–2 / 2–5 / 5–8 s）
- [ ] 具体型号/设备都有真实配图计划
- [ ] 转场落在段边界；转场表完整
- [ ] 色板、字体、字号、卡片母版、深度指示器已定
- [ ] 顶部覆盖层 y 坐标与安全边距已定
- [ ] 面包屑节点表已定：每节一个精炼关键词（2–4 字或一个英文词），不是章节标题
- [ ] 竖屏安全区已定（顶部 UI、内容区、字幕带、底部 UI、右栏）
- [ ] 字幕规范已定（两行、行级、英文高亮）

### 2.5 素材清单

- [ ] 每个素材有 ID、类型、描述、用于拍、来源/许可、处理方式、状态
- [ ] 真实图来源可溯源，许可明确
- [ ] 示意图/图表为自绘
- [ ] 无法获得的素材已替换/删除，未带病进入 assets
- [ ] 录屏、字体、音乐、音效也在清单内

## 3. Gate 2：素材包

- [ ] 每段有 `assets/`、`preview/`、`elements.json`
- [ ] 交付图层是透明 PNG；没有把背景/文字/面包屑烘焙进图层
- [ ] 真实图能认出型号；没有用“类似产品”冒充
- [ ] 抠图边缘在深底上无白边/灰边
- [ ] 暗图用 gamma 提亮，噪点可接受
- [ ] 跨来源图统一圆角/裁切/饱和度，像同一套图鉴
- [ ] 矢量 3× 超采样，细线无锯齿
- [ ] 每个元素有稳定 ID；`elements.json` 引用完整
- [ ] 坐标空间写明（画布像素/舞台局部）
- [ ] `elements.json` 字段类型全段一致
- [ ] 预览静帧与页面合成一致；`--plate` 不含覆盖层
- [ ] contact sheet 覆盖全部拍，文件名可读
- [ ] 素材许可/URL/访问日期已记录

## 4. Gate 2：旁白与时间轴

- [ ] 整片一次 TTS；若分段，已做音色一致性听测
- [ ] 读音层规则全部命中，`expect_occurrences` 无失配
- [ ] 上屏文本为 canonical；替读文本未上屏
- [ ] 旁白归一化实测 −16 LUFS、TP ≤ −1.5 dBTP
- [ ] 真峰超标时用 `--dynamic` 重跑过
- [ ] `timeline.json` 由 `make_film_narration.py` 生成，不是编稿时钟
- [ ] 段连续、拍递增、无重叠；`beat.id` 全局唯一
- [ ] 拍边界落在静音；没有切在字中间
- [ ] 章节卡窗口 = `[段首, 第一拍]`；卡片不盖人声
- [ ] 片尾卡在最后拍之后；音轨在卡前结束
- [ ] `subtitles.json` 一条 cue = 一个 sentence frame
- [ ] cue 不重叠、不越段、不伸进下一张卡
- [ ] 字幕数字与画面一致
- [ ] `beat.crumb` 全部落在 `crumb_nodes` 范围内（0-based，越界是 ERROR）
- [ ] `check_film.py` 无 ERROR；WARN 已处理或记录
- [ ] 每段 `narration.json` 已生成，含 sentence frame 与响度报告

## 5. Gate 2：播放页

- [ ] `npm run build` 通过（含 `tsc --noEmit`）
- [ ] 一个 1080×1920 舞台，等比缩放；无响应式重排改变构图
- [ ] 主时钟 rAF；画面/字幕/覆盖层都读 `timeline.json`
- [ ] 音频单侧校正（>250 ms 才 seek）；片尾卡暂停音频
- [ ] `?record=1` 隐藏控制条与时间码
- [ ] `?autoplay=1` 行为已记录（可能需一次手势）
- [ ] `?t=SEC` 定帧稳定；刷新两次一致
- [ ] `?badge=KEY` / `?safe=1` 仅评审可见
- [ ] 面包屑/关键词/品牌常驻；章节卡/片尾卡期间隐藏
- [ ] 面包屑是关键词且当前节高亮、其余压暗；`?t=` 抽查 3 个段各一次
- [ ] 内容自动居中：包围盒跳过 SVG/整帧图层，结果夹在 332–1410
- [ ] 同拍内元素一起移动，分步出现不抖
- [ ] 章节卡清屏，标题/短线/品牌正确；淡出接回舞台
- [ ] 片尾卡 logo 0.58→1.0 后停住，不循环
- [ ] 字幕带 1434–1542，两行内，英文高亮
- [ ] 安全区无遮挡；右栏互动区无关键信息
- [ ] 浏览器解码时长与 `meta.duration` 一致（容差内）

## 6. Gate 3：后期与成片

### 6.1 粗剪/锁画

- [ ] 全片看一遍，叙事完整、节奏成立
- [ ] 结构/节奏问题已改，不先抠细节
- [ ] `timeline.lock.json` 已冻结；锁画后无画面热改

### 6.2 调色/图像

- [ ] 跨来源图统一调色/圆角/裁切
- [ ] 深底细线/小字在手机亮度下可读
- [ ] 红色强调只用于标记/关键词

### 6.3 混音

- [ ] 旁白 −16 LUFS、TP ≤ −1.5 dBTP（实测）
- [ ] 音乐铺底约 −29 LUFS，ducking 6–10 dB
- [ ] attack 40 ms / release 700 ms；无抽气式起伏
- [ ] 片尾音乐延续并淡出，无突然断
- [ ] 分轨保留；改音乐不重录旁白

### 6.4 字幕

- [ ] 每条最多两行；英文高亮色一致
- [ ] 字幕与旁白同点；数字一致
- [ ] 章节卡/片尾卡无字幕
- [ ] 导出 UTF-8；导入播放器验证

### 6.5 母版

- [ ] 1080×1920 / 30 fps（或 brief 指定）
- [ ] H.264 High + AAC 48 kHz + `+faststart`
- [ ] 码率 10–12 Mbps；平台小样验证通过
- [ ] 首尾无黑帧/静音异常
- [ ] 章节卡、片尾卡完整
- [ ] 时长与 `timeline.json` 一致（容差内）
- [ ] 成片 MP4 上实测响度 −16 LUFS / TP ≤ −1.5 dBTP（不只是 mp3 读数）
- [ ] 母版晚于最后一次数据修改；出片后抽帧核对改动点
- [ ] 录屏无鼠标、通知、浏览器 UI

## 7. 交付前

- [ ] 成片 MP4 可播放；平台转码小样通过
- [ ] 竖屏封面 1080×1920；200 px 宽下标题可读
- [ ] 字幕文件（SRT/ASS）与成片一致
- [ ] 元数据：标题、简介、标签、章节时间点
- [ ] 参考资料/音乐署名/素材许可齐全
- [ ] 无 key、token、密码、个人隐私信息
- [ ] `check_secrets.py` 通过
- [ ] `check_ascii.py` 通过（工程文件）
- [ ] `check_film.py` 通过
- [ ] 工程可重建：`run.bat`/`Makefile` 能从头跑通（缓存缺失时）
- [ ] `.tmp` 未混入交付包
- [ ] `README.md` 写明当前版本、如何播放/重建、已知缺口
- [ ] `review_log.md` 记录 Gate 3 结果

## 8. Definition of Done

同时满足以下条件才算完成：

1. Gate 1 / 2 / 3 均为 `Approved`，记录可查。
2. 成片在目标平台小样验证通过，音画同步、字幕正确、响度达标。
3. 所有事实有来源，所有真实图有许可，所有示意图为自绘。
4. 工程能从 `pre-production.md` + `toolbox/` + 素材重建；不依赖某次手工操作。
5. 无凭证/隐私泄露；`.tmp` 与预览产物未进入交付包。
