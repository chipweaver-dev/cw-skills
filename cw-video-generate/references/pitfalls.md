# 踩坑库：症状 → 根因 → 修法

先按症状定位大类，再逐条核对。所有数值都是起点，不是宇宙常数；改参数后要重新实测。

## 0. 一分钟分诊

| 症状 | 先查 |
|---|---|
| 画面比声音早/晚 | `timeline.json` 是不是由 `make_film_narration.py` 生成；页面有没有第二套时钟 |
| 字幕整体漂移 | 是否按字符位对齐；是否用了 sentence frame；读音层替换是否改变字符数 |
| 字幕个别句子晚 | 该拍是否以数字/拉丁字母开头；sentence frame 的起点 vs 音频 RMS 起点 |
| 面包屑就是章节标题 / 没有高亮 | `crumb_nodes` 是不是从章节卡标题批量填的；页面有没有读 `beat.crumb` |
| 某拍元素整体偏移 | 坐标是原图像素还是舞台坐标；是否加了舞台原点 |
| 元素跑到屏幕外/抖动 | 包围盒测量是否把整帧图层/SVG 算进去；`Math.min` 是否吃到 `NaN` |
| 旁白被音乐盖住 | 音乐铺底 LUFS、ducking 深度、release；是否按旁白包络 |
| 终混响度不对 | 看 `measured_after`，不是目标值；真峰是否超标 |
| 片尾音乐断了 | 和弦循环是否在片尾卡前停止；尾和弦是否提前 release |
| 页面没声音 | 浏览器自动播放策略；是否先有一次用户手势 |
| 页面白屏 / 资产 404 | 静态服务器的文档根是不是根绝对路径（`/post-production/...`）解析到的那一层 |
| 预览页怎么刷都不是本项目 | 端口上是不是别的项目的 dev server |
| 改了数据，成片还是旧版 | 有没有旧渲染任务还在跑，最后写回母版 |
| 简介里的时长/章节时间与成片对不上 | 文案是在平台后台手写的，还是从 `timeline.json` 派生的 |
| 时长对不上 | MP3 padding；ffprobe 容器时长 vs 浏览器解码时长 |

## 1. TTS 与旁白

### 1.1 逐拍/逐段请求导致音色漂移

**症状**：后面章节的音色、语速、情绪和第一章不一致；拼接处像换了人。

**根因**：每次 TTS 请求都是独立渲染，同一 speaker 也会在请求间漂移。

**修法**：整片一次请求。若文本超长必须分段，按**叙事单元**分（不是按拍），每段单独渲染后做拼接听感验证；不要按 beat 请求。

### 1.2 语速假设偏低，成片大量留白

**症状**：按 3.2–3.6 字/秒写的脚本，合成后每段都短一大截，画面空等。

**根因**：旧假设没有用当前音色实测。默认中文女声实测约 4.3–4.5 字/秒。

**修法**：先用一条 20–30 秒样本测 `字数 / 音频秒数`；预算按 4.2 字/秒反写，留 5–8% 停顿余量。脚本定稿前再测一次。

### 1.3 读音层替换次数失配，静默改错文本

**症状**：改了旁白后某条替读规则不再命中，但合成照常进行，读音又错了。

**根因**：替换表只在“找到就替换”，没有校验出现次数。

**修法**：每条规则带 `expect_occurrences`；合成前统计整片 `canonical` 出现次数，不符直接 `raise`，且在网络请求之前退出。改旁白时同步改计数。

### 1.4 读音层改变了字符数，字幕错位

**症状**：含 `DRAM`、`1Rx16` 的句子字幕整体偏移。

**根因**：按字符位置把 sentence frame 映射回原文；替读后字符数变了。

**修法**：字幕按 **sentence frame** 对齐；frame 文本做 `reading → canonical` 反向替换。frame 到 beat 的归属先用去空格字符位置精确匹配，失败后按字符质量比例分配（`group_frames_proportional`）。

### 1.5 数字/拉丁字母开头的拍，字幕偏晚

**症状**：旁白已经开口，字幕还停在上一条；集中在“30 纳秒”“DDR4”“1Rx16”这类开头。

**根因**：TTS 的 sentence frame 起点对数字/拉丁词偏保守；不能直接当声学起点。

**修法**：抽几条与音频 RMS 起点对比；只做**单侧**修正（字幕早于音频才推迟，不把已经对齐的句子提前）。保持修正量小且可复现，不要手调每条。

### 1.6 代理导致 TTS 请求失败

**症状**：`check_hostname requires server_hostname` 或连接超时；浏览器能上网。

**根因**：系统代理是 `https://`，urllib3 不能包装该 scheme。

**修法**：在请求前设置 `NO_PROXY` / `no_proxy` 包含 TTS 域名（示例：`openspeech.bytedance.com`），走直连。不要把代理地址写进产物。

### 1.7 key 出现在日志/产物里

**症状**：异常栈、调试打印、`run.bat`、review 文档里出现 key。

**根因**：共享客户端把 headers/请求体整个打印；或把 key 当命令行参数传入。

**修法**：key 只从环境变量/`.env` 读；异常只打印响应状态与错误码；任何日志过滤 `Authorization`；交付前 `check_secrets.py`。

### 1.8 TTS 响应没有词级时间戳

**症状**：只有整段音频时长，没有 sentence/word 起止；拍边界只能估算。

**根因**：接口参数/版本不对，或返回结构被裁剪。

**修法**：拒绝用估算值硬切；换用带 sentence frame + `words[].startTime/endTime` 的接口/参数。没有词级时间就无法做音频主导时间轴。

### 1.9 MP3 容器时长与解码时长不一致

**症状**：ffprobe 报 284.784 s，浏览器解码 284.748 s；片尾卡差几十毫秒。

**根因**：MP3 编码器 padding/帧对齐。

**修法**：页面时钟以浏览器 `decodeAudioData` 的时长为准；ffprobe 只做容器层检查。比较时给 0.05–0.1 s 容差。

## 2. 时间轴与字幕

### 2.1 只跑 `make_timeline.py`，时钟退回编稿时长

**症状**：页面显示 330 s，音轨只有 280 s；后半段画面空转。

**根因**：`make_timeline.py` 生成的是**编稿时钟**；播出时钟必须由 `make_film_narration.py` 用实际 TTS 时间重写。

**修法**：改完 `timeline_source.json` 后重跑 `make_film_narration.py`；`make_timeline.py` 只用于审稿。把这条写进 `run.bat` 注释。

### 2.2 章节卡盖住旁白

**症状**：卡片期间已经有人声，或卡片结束后第一句被切掉。

**根因**：静音拼接点落在语音里，或卡片时长与 splice 时长不一致。

**修法**：卡片静音插在段首第一拍的实际起点前（该点已在两句之间的静音里）；`segment.card.t0 == segment.t0`，`card.t1 == 第一拍.t0`。卡是 display-only，不重合成旁白。

### 2.3 片尾卡期间旁白还在说

**症状**：logo 放大时还有最后一句人声。

**根因**：片尾卡从最后一句的 `end` 开始，而不是从 `end + TAIL` 开始；或音轨本身更长。

**修法**：`end_card.t0 = 最后一拍.t1`（已含 `TAIL`）；音轨在卡片前结束；音乐可继续。页面在 `now > audio.duration` 时暂停音频，不 seek 越界。

### 2.4 字幕停留伸进下一张卡

**症状**：章节卡清屏后，字幕还挂在底部。

**根因**：cue 的 hold 只夹了下一 cue，没有夹段末。

**修法**：`hold_end = min(cue.t1 + 0.35, next_cue.t0, segment.t1)`；卡片/片尾卡期间页面不渲染字幕。

### 2.5 字幕 cue 重叠

**症状**：两条字幕同时显示，或高亮跳变。

**根因**：sentence frame 的结束时间晚于下一句开始；或 hold 延长没有夹下一 cue。

**修法**：生成后按 `t0` 排序，`t1 = min(t1, next.t0)`；`check_film.py` 检查重叠。

### 2.6 段边界不在第一拍

**症状**：段切换时画面已经换了，旁白还在上一段最后一句。

**根因**：段边界用了编稿预算或最后一个 beat 的结束，而不是第一拍的实际起点。

**修法**：`segment.t0 = first_beat.t0 - card_lead`；`segment.t1 = last_beat.t1`（最后一段可延到片尾卡）；转场点用 `segment.t0 + card_lead`。

### 2.7 拍切点落在字中间

**症状**：换镜时听到半个字，或画面在说话中途跳。

**根因**：用了固定预算切点，或 `gap` 计算把重叠当成了正间隙。

**修法**：按 §5.4 算法：`gap < 0.2` 取中点；否则 `max(prev_end + MIN_GAP, next_start - ONSET)`；`gap < 0` 按 0 处理并告警；切点必须递增。

### 2.8 frame 分组失败，整片报错

**症状**：`group_frames_exact` 返回 `None`；引擎把文本改写了（数字读法、标点）。

**根因**：精确字符位置匹配要求引擎文本与输入完全一致。

**修法**：保留精确匹配为首选；失败时用 `group_frames_proportional` 按字符质量分配。记录 `frame_mapping`（`character-position` / `proportional`），便于复查。

### 2.9 字幕用了替读文本

**症状**：屏幕上出现“D ram”“航地址”“1 rank 乘 16”。

**根因**：直接用了 frame 文本，没有反向替换。

**修法**：生成 cue 前 `reverse_reading`；上屏只用 canonical。反向替换顺序与正向相反，避免嵌套规则互相污染。

### 2.10 旁白数字与画面不一致

**症状**：旁白说 3200，画面写 3000；或年份差一年。

**根因**：脚本、画面、字幕各自维护数字。

**修法**：数字只从 `research/facts.json` 引用；改数字先改表，再重跑脚本/页面。评审时抽查每个上屏数字的来源 ID。

### 2.11 时间取整造成 1 帧误差累积

**症状**：段边界有 1–2 帧的音频/画面错位；多次重算后越来越偏。

**根因**：每一步都四舍五入到 2 位，误差累积。

**修法**：内部用浮点，输出统一 `round(x, 3)`；只在写 JSON 时取整。比较用容差（0.02 s），不要用 `==`。

### 2.12 面包屑写成了章节标题，没有关键词也没有高亮

**症状**：面包屑一行是「品牌 / 项目 / 完整章节标题」，观众看不出讲到哪；标题是整句，横排很长，且整条同色。

**根因**：`crumb_nodes` 从章节卡标题批量填（那是当时唯一现成的字符串），没有单独维护短标签；页面也从不读 `beat.crumb`。

**修法**：面包屑文案单独建表（如 `toolbox/crumbs.json`：段 ID → 短词），`crumb_nodes` 只从这张表取，缺条目才退回标题。标签是术语/名词（`flit`、`router`、`路由`），一节 2–4 字或**一个**英文词，不是句子。页面按 `beat.crumb` 点亮当前节（正文色），其余压暗（dim），分隔符用发丝色——读作"位置"，不是"菜单"。

### 2.13 `crumb` 索引基不一致，长期没人消费所以没暴露

**症状**：高亮永远差一格；索引 1 指向第二个节点。

**根因**：生成端 `int("C1"[1:])` 写出 1，而 `crumb_nodes` 从 0 开始；页面一直没用这个字段，数据错了也没有任何现象。

**修法**：索引与节点表一律 0-based，生成时 `assert 0 <= crumb < len(crumb_nodes)`，`check_film.py` 也查越界。更要紧的是：**字段没人消费不等于数据正确**——评审时把"已写入但无人读取"的字段单独列出来核对一遍，别等页面开始用才暴露。

## 3. 素材与坐标

### 3.1 Windows 中文路径读图失败

**症状**：`cv2.imread` 返回 `None`；路径明明存在。

**根因**：OpenCV 在 Windows 对非 ASCII 路径支持差。

**修法**：用 Pillow（`Image.open`）读写；或先 `np.fromfile` + `cv2.imdecode`。所有素材脚本统一用 PIL。

### 3.2 抠图后白边/灰边

**症状**：透明 PNG 放在深底上有一圈浅色描边。

**根因**：原图背景是白/浅灰，alpha 边缘保留了背景色。

**修法**：用 alpha matte 或边缘收缩（erode）去掉 1–2 px；在深底上合成检查；不要用“变暗”掩盖白边。

### 3.3 暗色厂商图提亮后噪点爆炸

**症状**：芯片图提亮后颗粒感很重，颜色发灰。

**根因**：用 gain/乘法提亮，放大了噪声。

**修法**：用 gamma（如 1.2–1.6）提亮中间调；需要时先轻降噪；黑位不要抬太多。

### 3.4 裁切把标签/引脚切掉

**症状**：芯片型号丝印被裁掉一半，观众认不出。

**根因**：按固定比例/中心裁切，没有看内容。

**修法**：按边缘能量/内容包围盒找主体，留 3–5% 边距；型号丝印必须完整；裁切后在目标尺寸下检查可读性。

### 3.5 SVG 元素没有 `offsetTop`

**症状**：内容居中计算出现 `NaN`，整拍消失或跳到屏幕外。

**根因**：SVG 元素不是 `HTMLElement`，没有 `offsetTop/offsetHeight`；`Math.min` 吃到 `NaN` 后全部变 `NaN`。

**修法**：`instanceof HTMLElement` 再量；跳过 SVG/非 HTML 元素；所有数值进 `Math.min` 前做 `Number.isFinite` 检查。

### 3.6 整帧图层让包围盒永远等于全屏

**症状**：每拍内容都居中不了，或者所有拍都偏到同一位置。

**根因**：某个背景/整帧 plate 宽度约等于画布，包围盒被它撑满。

**修法**：测量时跳过宽度/高度接近画布的图层；只量内容层。整帧底板用固定偏移，不参与自动居中。

### 3.7 分步出现的元素导致画面抖动

**症状**：同一拍内，元素一出现整组就跳一下。

**根因**：每帧重新测量“当前可见元素”的包围盒，可见集合变化 → 中心变化。

**修法**：按整拍测量所有元素（包括尚未出现的），一次算好偏移；同一拍内共享。或者给未出现元素保留占位。

### 3.8 坐标是局部坐标还是画布坐标

**症状**：某组标签整体偏了舞台原点那么多。

**根因**：`stage_label`/`ruler_label` 用舞台局部坐标，其他元素用画布坐标；消费端没加原点。

**修法**：`elements.json` 的 `notes` 写明坐标空间；页面按字段类型加舞台原点；不要靠“看起来差不多”手调。

### 3.9 `elements.json` 字段类型不一致

**症状**：页面报 `labels.map is not a function`。

**根因**：同一字段在某段是数组，在另一段是对象。

**修法**：统一 schema；页面仍做防御（`Array.isArray` / `Object.values`）；在生成脚本里加类型校验。

### 3.10 预览静帧里有面包屑，页面又画一遍

**症状**：底板上有一条面包屑，页面顶部又有一条；位置还不一样。

**根因**：`compose_still.py` 默认把页面覆盖层烘焙进图。

**修法**：给 `--plate` 选项，输出不含面包屑/关键词/字幕的底板；预览静帧可以带覆盖层，但只用于评审。

### 3.11 预览与页面不一致

**症状**：contact sheet 看着对，页面里元素大小/位置不对。

**根因**：预览脚本和页面各有一套字号/坐标。

**修法**：以页面为准；预览脚本读同一份 spec/`elements.json`；评审时用 `?t=` 截图对照 contact sheet。

### 3.12 矢量边缘锯齿

**症状**：细线/圆环在 1080 宽下毛糙。

**根因**：按目标尺寸直接绘制，抗锯齿不足。

**修法**：3 倍尺寸绘制再缩小（LANCZOS）；或直接由页面渲染 SVG；导出 PNG 时保留透明底。

### 3.13 字体回退改变排版

**症状**：开发机好看，交付机换行/溢出。

**根因**：用了系统字体，不同机器度量不同。

**修法**：交付前自托管授权字体（WOFF2）；CSS `font-display: swap`；在目标机器/浏览器实测。开发期回退可以，但不能作为交付依据。

### 3.14 用 AI 生成“历史照片”

**症状**：观众发现芯片/设备图是假的；或授权无法说明。

**根因**：为了省事用生成图补位。

**修法**：真实图只用可溯源图库/厂商/博物馆；示意图自绘；找不到就换条目或删除。AI 只用于非历史、非实物的抽象纹理。

### 3.15 水印/隐私处理未经确认

**症状**：裁掉了厂商水印，或保留了别人的个人信息。

**根因**：默认“裁掉就行”。

**修法**：先确认授权与作者要求；记录处理方式；涉及个人信息必须打码/删除。不要擅自去除版权水印。

## 4. 播放页与浏览器

### 4.1 `?autoplay=1` 没声音

**症状**：画面在动，音频不出声；按一下 Space 就好了。

**根因**：浏览器自动播放策略要求用户手势。

**修法**：录屏前先点一次页面/按 Space；或在页面加“点击开始”遮罩。不要把“无手势自动有声”当成可交付行为。

### 4.2 音频追时钟导致反复 seek/卡顿

**症状**：音频每隔几秒顿一下，或出现金属声。

**根因**：双向校正，阈值太小；`currentTime` 设置过频。

**修法**：单侧校正，漂移 > 0.25 s 才 seek；只追落后，不追超前；seek 后给 100–200 ms 稳定期。

### 4.3 片尾卡 seek 越界

**症状**：控制台报 `currentTime` 超出范围；或片尾卡音频突然跳回开头。

**根因**：主时钟超过音轨时长后仍把 `now` 写进 `audio.currentTime`。

**修法**：`if (target >= audio.duration) { audio.pause(); return; }`；片尾卡期间不再同步音频。

### 4.4 Vite 引用不到素材

**症状**：`import.meta.glob` 为空；或 `fs.allow` 报 403。

**根因**：glob 的根不对；素材在 Vite 根之外。

**修法**：`server.fs.allow` 放到任务根；别名指向 `production/<version>`；glob 用相对别名路径，打印 key 检查；`assetsInlineLimit: 0` 避免大图内联。

### 4.5 `?t=` 定帧不稳定

**症状**：同一个时间点刷新两次，画面不同。

**根因**：字体/图片未加载完就截图；或有 CSS 动画不跟主时钟。

**修法**：`?t=` 时暂停主时钟；等 `document.fonts.ready` + 图片 `decode()`；所有动画由 `t` 计算，不用 CSS keyframes 自由运行。

### 4.6 录屏有黑边/比例不对

**症状**：上下或左右黑边；内容被裁。

**根因**：视口不是 9:16；或舞台用了 `object-fit: cover`。

**修法**：录屏区域/窗口设成 1080×1920；舞台等比缩放并留边由页面背景填充；不要用裁切改变构图。

### 4.7 页面在后台标签页停住

**症状**：录屏时画面卡住，切回来又好了。

**根因**：浏览器对后台标签页的 rAF 节流。

**修法**：录制时保持页面在前台/全屏；不要最小化；关闭省电模式。

### 4.8 React 重挂载导致闪烁

**症状**：段切换时整页白一下，或字幕闪。

**根因**：key 变化导致舞台/覆盖层重挂载；或每拍新建 DOM。

**修法**：舞台容器保持挂载，只换内部图层；用 crossfade（约 260 ms）；覆盖层独立于场景。

### 4.9 构建过不了类型检查

**症状**：`npm run build` 报 TS 错误，但 `npm run dev` 能跑。

**根因**：Vite dev 不做完整类型检查；`build` 里 `tsc --noEmit` 才暴露。

**修法**：交付前必须跑 `npm run build`；类型错误不绕过；给 JSON 数据加显式类型和运行时防御。

### 4.10 缓存导致改了没生效

**症状**：素材/字幕改了，页面还是旧的。

**根因**：浏览器缓存或 Vite 依赖预构建缓存。

**修法**：硬刷新（Ctrl+Shift+R）；必要时删 `node_modules/.vite`；音频/图片 URL 加版本查询参数。

### 4.11 端口上跑着另一个项目

**症状**：`curl http://127.0.0.1:5180/post-production/web/app.js` 返回 200，打开页面却完全不是本项目；改了文件不生效。

**根因**：同一工作区有多个工程，端口被另一个项目的 dev server 占着，目录名和相对路径又恰好相同。

**修法**：每个任务用自己指定的端口，不要复用别人的默认端口。启动前确认监听者是谁（`netstat -ano` 找 PID，再看该 PID 的命令行）；HTTP 200 只证明"这个端口有人在服务"，不证明是你。验证方式是 curl 一个**本任务独有**的文件并检查内容，而不是只看状态码。

### 4.12 静态服务器文档根选错，页面白屏

**症状**：`index.html` 能打开，`app.js`、`scenes.json` 全 404，控制台一片红；或反过来，主页是别的项目的目录列表。

**根因**：页面用根绝对路径（`/post-production/...`、`/production/...`），文档根必须设成这些路径的公共父目录（任务根，例如 `video/`），而不是 `post-production/web/`。

**修法**：`python -m http.server <port> --bind 127.0.0.1 --directory <task_root>`；起好后逐个 curl 页面、脚本、数据、音频、字体，确认全部 200。注意 `http.server` 不支持 Range：20 MB 级音频首次拖动要等整段下载，要看流畅预览就换支持 Range 的服务器，别误判成"页面卡了"。

## 5. 音乐与混音

### 5.1 素材站无 key / 403，卡住

**症状**：Pixabay 等返回 403；环境里没有音乐 API key。

**根因**：没有可用授权渠道，或 key 未配置。

**修法**：不要反复试；改用本地合成铺底（numpy/scipy），可精确对齐时间轴且无授权风险。若必须用素材站，先确认 key 与许可，再进入制作。

### 5.2 片尾卡前音乐突然静音

**症状**：最后 2–3 秒只有画面，没有音乐。

**根因**：和弦循环的停止条件早于片尾卡（如 `start < end - 2`），或最后一个和弦 release 太早。

**修法**：循环跑到片尾卡前；最后一拍用终止和弦并 `release=0` 保持到片尾结束；片尾最后 2 s 淡出。

### 5.3 终止和弦与前一和弦半音冲突

**症状**：片尾收束听起来“打架”/刺耳。

**根因**：循环停在 Cadd9，直接接 Dm，导音冲突。

**修法**：片尾前最后一个循环和弦强制为终止和弦（或属和弦），再进 Dm(add9)；用听感 + 频谱确认。

### 5.4 合成缓冲区长度不一致，出现爆音/空隙

**症状**：和弦交界有 click，或结尾少一个采样。

**根因**：用浮点秒数反算缓冲区长度，不同路径取整不同；`pad_voice` 内部又按秒重算长度。

**修法**：所有 DSP 函数接收采样数 `n`，不接收秒；写入时用同一个 `n_len`；边界 `min` 到缓冲区剩余长度。

### 5.5 `--duck-db` 参数不生效

**症状**：改深度参数，听感没变化。

**根因**：参数解析了但没传进 `duck_envelope`。

**修法**：把 `depth_db` 作为显式参数传入；用测试信号验证增益曲线；不要只改 CLI 帮助文本。

### 5.6 `subprocess` 文本/字节混用

**症状**：`TypeError: memoryview: a bytes-like object is required, not 'str'`。

**根因**：`subprocess.run(..., input=bytes, text=True)` 同时要求文本模式。

**修法**：传 bytes 时不要 `text=True`；或传 str 并指定 `encoding="utf-8"`；stderr 手动 decode。

### 5.7 终混响度“目标对了但实测不对”

**症状**：脚本打印 −16 LUFS，平台上仍偏小/偏大。

**根因**：引用的是目标值，不是 `measured_after`；或用了单遍 loudnorm。

**修法**：读报告里的 `measured_after`；两遍归一化；真峰超标用 `--dynamic`；最终用 ffmpeg `loudnorm` 再测一次。

### 5.8 音乐抽气式起伏

**症状**：旁白一停音乐猛涨，一说话又猛掉。

**根因**：ducking attack/release 太短，或包络阈值太窄。

**修法**：attack 40 ms、release 700 ms；阈值 −48…−30 dBFS；包络平滑；必要时降低 duck 深度（6 dB）而不是加快恢复。

### 5.9 分段归一化导致段落间音量跳变

**症状**：每段开头音量突然变大/变小。

**根因**：对每段单独做 loudnorm。

**修法**：整片一条旁白只归一化一次；分段只做剪辑，不做独立响度归一化。

### 5.10 没音乐也没问用户

**症状**：成片交付后用户问“怎么没有音乐”。

**根因**：默认省略了音乐方案。

**修法**：每个视频必须有音乐方案；不用音乐必须在 brief 里取得用户明确同意并记录。

### 5.11 响度在 mp3 上达标，封装进 MP4 后偏了

**症状**：`film_full_scored.mp3` 实测 −16.0 LUFS，成片 MP4 再测是 −16.2 LUFS。

**根因**：AAC 编码与容器封装会小幅改变积分响度与真峰。

**修法**：终混达标后再对**交付的 MP4**跑一次 `loudnorm` 测量，报告里同时写 mp3 与 MP4 两个读数；±0.5 LU 内可接受，超出回混音重跑。

## 6. 环境与工具

### 6.1 FFmpeg 不在 PATH

**症状**：脚本报 `ffmpeg not found`；命令行却能用。

**根因**：Python/子进程的 PATH 与交互 shell 不同。

**修法**：脚本先 `shutil.which`，再查本机已知目录/环境变量 `FFMPEG_DIR`；仍找不到就报明确错误。不要把绝对路径写进交付 JSON。

### 6.2 Python 3.8 不支持新语法

**症状**：`TypeError: 'type' object is not subscriptable`（`list[str]`）或 `SyntaxError`（`match`）。

**根因**：开发用了 3.10+，运行环境是 3.8。

**修法**：`from __future__ import annotations`；用 `typing.List/Dict`；避免 `match`、`X | Y`；CI/入口固定解释器版本。

### 6.3 子进程输出乱码/解码失败

**症状**：`UnicodeDecodeError`，或中文路径输出乱码。

**根因**：Windows 默认代码页不是 UTF-8。

**修法**：`subprocess.run(..., text=True, encoding="utf-8", errors="replace")`；路径用 `pathlib.Path`；必要时设 `PYTHONUTF8=1`。

### 6.4 Git Bash 与 cmd 语法混用

**症状**：`run.bat` 里用了 `&&`/`||` 以外的 POSIX 写法；或 bash 里用了 `%~dp0`。

**根因**：两个 shell 语法不同。

**修法**：Windows 入口用 `.bat`（`%~dp0`、`goto :err`）；Linux 入口用 `Makefile`/`.sh`；不要互相复制命令。

### 6.5 中文路径导致工具链失败

**症状**：FFmpeg/PIL/Node 某个环节找不到文件。

**根因**：工具对非 ASCII 路径支持不一致。

**修法**：能改路径就改；不能改就用 PIL/`pathlib`；子进程传 `str(path)`；避免在 `run.bat` 里手拼引号。

### 6.6 从任务目录调用 skill 脚本，相对路径算错

**症状**：`node ../.claude/skills/<skill>/scripts/cdp_capture.mjs ...` 报 `MODULE_NOT_FOUND`。

**根因**：按"离 `.claude` 有多近"估层级；任务目录常有 `video/`、`project/` 这类中间层，实际是 `../../../`。

**修法**：先用 `pwd` + 绝对路径跑通，再决定是否相对化；文档示例统一写 `<skill>/scripts/...` 占位，不写死层级。

### 6.7 脚本 print 中文，Windows 控制台报错或乱码

**症状**：`UnicodeEncodeError: 'gbk' codec can't encode`，或输出变成问号方块。

**根因**：控制台默认代码页不是 UTF-8；而且工程脚本本来就不该出现中文（红线 9）。

**修法**：工程脚本只 print ASCII（进度、计数、路径），中文只进 `.md`。临时排查可设 `PYTHONIOENCODING=utf-8` 或 `sys.stdout.reconfigure(encoding="utf-8")`；一次性脚本要用中文文案时写 `\u` 转义，保持源码 ASCII。

## 7. 流程与评审

### 7.1 Brief 没定死就开工，后期大返工

**症状**：做完发现时长不对、画幅不对、风格不对。

**根因**：brief 缺字段或“先做起来再说”。

**修法**：开工前逐项确认 §2.1 的八项；总时长、画幅、是否要音乐、受众必须先定。任何模糊项先问。

### 7.2 素材 ID 漂移

**症状**：脚本引用了 `P04`，素材清单里没有；或同一个 ID 指两张图。

**根因**：脚本、spec、清单各自命名。

**修法**：一份素材总表；ID 全局唯一；脚本只引用 ID；缺 ID 直接失败。删/换素材时同步改所有引用。

### 7.3 删了一段，后面全错

**症状**：段 ID、预算、面包屑、转场、关键词全部对不上。

**根因**：删段只改了脚本，没有重算编号与预算。

**修法**：删段后重排 ID、重算预算之和、重绑面包屑/舞台/关键词，再全片过一遍。不要保留“空段”当占位。

### 7.4 未过 Gate 就跑完整流水线

**症状**：brief 还没批，素材/TTS/混音全做完了，返工成本巨大。

**根因**：想一次跑完。

**修法**：Gate 1 批准前不做正式素材与 TTS；Gate 2 前不终混；每个 Gate 落 `review.md` + `review_log.md`。

### 7.5 版本混用

**症状**：页面读 v0.2 的 timeline，素材却是 v0.1 的。

**根因**：目录没有版本隔离，或脚本默认路径写死。

**修法**：版本目录隔离；`timeline.json` 的 `source` 指向对应 pre-production 版本；`run.bat` 显式传 `--root`/版本。

### 7.6 `.tmp` 里的东西被当成交付物

**症状**：交付包混入试混、截图、旧版音频。

**根因**：临时文件没有边界。

**修法**：`.tmp` 不交付；交付前按清单核对；正式产物一律在 `production/` / `post-production/`。

### 7.7 评审意见太虚，无法收敛

**症状**：“再高级一点”“节奏再快一点”，改了几版还在原地。

**根因**：反馈没有指到具体时间点/元素/标准。

**修法**：反馈带 `?t=` 时间点、截图、期望值；分阻塞/非阻塞；每条对应一个可验收动作。

### 7.8 已裁定的问题反复讨论

**症状**：字幕行级 vs 逐字、术语读法、某段取舍，每次评审都重开。

**根因**：没有决策记录。

**修法**：`decision_log` 记录 `id/date/decision/reason/scope`；后续引用 ID，不重复讨论。改裁定要写明新理由。

### 7.9 预算之和不等

**症状**：各段预算加起来比总时长多/少几十秒。

**根因**：手写预算，后期改了段长没回写总数。

**修法**：用脚本校验 `sum(budget) == total`；改任何段预算都重算；留 5–8% 余量但计入总数。

### 7.10 字数超了靠加速旁白补救

**症状**：语速快到听不清，或 TTS 发音变形。

**根因**：脚本超预算，用 `speech-rate` 硬压。

**修法**：删内容/拆段/延长总时长；不要用加速补救。旁白速率保持 0，语速由文本长度控制。

### 7.11 具体型号没有配图

**症状**：讲到某型号，画面只有文字卡/示意图。

**根因**：素材清单没把“型号必须配图”当硬约束；到 assets 阶段才发现找不到。

**修法**：research 阶段就收集图；script 阶段确认每个型号有合规图；找不到就换型号/删该拍，不带病进入 assets。

### 7.12 参考资料页塞满

**症状**：片尾小字密密麻麻，一条都读不完。

**根因**：把所有来源都上屏。

**修法**：竖屏只上屏 3–5 条核心来源；其余放描述区/`research/sources.md`；每条停留可读。

### 7.13 横屏构图直接裁成竖屏

**症状**：关键信息被裁掉，字幕压住主体。

**根因**：把 16:9 当 9:16 用。

**修法**：竖屏重新排版：规格卡纵向、示意图重排、字幕下移；用 `?safe=1` 检查。

### 7.14 按猜的字段路径读写数据，`KeyError`

**症状**：`KeyError: 'crumb'` / `KeyError: 0`；同一份 JSON，有时能取到有时不行。

**根因**：按印象假设结构（以为顶层 `beats` 是数组，其实是按 id 的字典），没有先看生成端代码和 `pipeline.md` 的数据契约。

**修法**：先读**生成端**写这份 JSON 的地方，再读 `references/pipeline.md` §4 的契约；拿不准就一次性打印结构（`type()` + 前三层键名）。契约缺失时补到 `pipeline.md`，不要在下游用兜底猜测掩盖。

### 8.1 首尾黑帧/静音

**症状**：成片开头 0.5 s 黑屏；结尾突然黑。

**根因**：录屏起止点没对齐页面；或编码器补帧。

**修法**：录屏从 `t=0` 开始，先等页面稳定；结尾多录 1 s 再裁；用 ffprobe/抽帧检查首尾。

### 8.2 平台二次压缩后字幕糊

**症状**：本地清楚，上传后字幕发虚。

**根因**：码率太低/字体太细/对比度不足。

**修法**：1080×1920 用 10–12 Mbps；字幕字号不低于 30；避免纯细体；深底浅字保证对比度。

### 8.3 封面在信息流里不可读

**症状**：封面缩略图看不清标题。

**根因**：字太小、信息太多、主体不在中部。

**修法**：封面单独设计：一个主体 + 一行短标题；在 200 px 宽下检查；不要把整张规格卡当封面。

### 8.4 字幕文件编码/换行问题

**症状**：导入平台后乱码或一行到底。

**根因**：SRT 用了非 UTF-8；或换行符不对。

**修法**：UTF-8（可带 BOM）；CRLF/LF 按平台；每条不超过两行；交付前用播放器导入验证。

### 8.5 编码参数不兼容

**症状**：平台转码失败/黑屏；或文件过大。

**根因**：用了不支持的 profile/pixel format；或 CRF 过低。

**修法**：H.264 High、`yuv420p`、AAC 48 kHz、`+faststart`；CRF 18–20，maxrate 10–12 Mbps；先上传小样验证。

### 8.6 旧渲染任务还在跑，交付了旧画面

**症状**：数据改好、新渲染也跑完，成片里的面包屑/字幕还是旧版；或两个渲染任务抢同一个输出目录。

**根因**：改数据之前启动的渲染没停，几十分钟后它把旧画面写回母版，覆盖了新文件。

**修法**：改任何会被渲染读取的数据之前，先停掉在跑的渲染任务，并且同时只允许一个渲染任务。出片后抽帧核对改动点（`ffmpeg -ss <t> -frames:v 1 ...`），不要只看文件时间戳。

### 8.7 ASCII 扫描把浏览器 profile 一起扫了

**症状**：`check_ascii.py` 报若干非 ASCII 文件，路径全在 `.tmp/render/profile-*/`（Chrome 扩展 JS），不是本项目代码。

**根因**：扫描器遍历整个任务根，渲染时浏览器自己写下的临时文件也被扫进来。

**修法**：`check_ascii.py` 默认跳过 `.tmp`（本 skill 已改）；扫描前仍应清掉 `.tmp/render/profile-*` 与 `frames/`。判读结果时先看路径——工具缓存里的命中不是工程违规，但也不要为此把规则放宽。

### 8.8 发布文案与成片对不上

**症状**：简介写着 15:00，成片 15:51；章节时间点按旧版写，点进去偏半分钟；标题在平台后台改过一版，README 与封面还是旧的。

**根因**：文案是发布当天在平台后台手写的，片长与章节靠记忆或旧稿抄；同一份信息在 README、pre-production、平台后台各存一套，返工后没人同步。
